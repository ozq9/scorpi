What is Scorpi?

A desktop AI agent that runs on your machine. The app, your chats and your keys stay on your PC; prompts go only to the model provider you choose.

  • Live canvasAnswers come with charts, maps, tables and cards next to the chat.
  • AgentsCoder, Researcher, Writer, Analyst and Operator take bigger jobs in the background. Create your own from chat, with schedules.
  • CodingThe Coder plans, builds, tests and fixes projects, checks every edit, and asks a second model for a review. In the app or in a terminal. More below.
  • GitHubClone your repos or open any folder. A side panel shows every helper agent, a live preview with its console, the diff of each run (undo in one click), a terminal, commits, pull requests and issues the Coder fixes.
  • Any modelOllama, Groq, Gemini, OpenRouter, Ollama Cloud, Cloudflare and 20 more free tiers. Falls back to the next model when a free tier runs out.
  • VoicePush to talk with local speech recognition. Interrupt it mid-sentence.
  • DesktopHold Ctrl + Win over any window and ask about it. Scorpi sees what you mean.
  • MCP and pluginsConnect MCP servers over stdio or HTTP. Plugins add panes, commands and hooks.
  • PhoneOpen it on your phone over Wi-Fi or Tailscale. Your PC does the work; a pairing PIN locks it.

The coding agent

Tell the Coder what to build or fix. It maps the code, shows you a plan, edits with a check after every change, runs the tests until they pass, and keeps a checkpoint of every run so you can undo it. On any model, free ones included.

Fig 2. The same agent in a terminal: scorpi-code in any folder, with the app's models, keys and checkpoints.

  • Plan firstIt reads the code and proposes a plan. Approve it, or say what to change and it revises. Nothing is touched before you agree.
  • Real code toolsRegex search, a map of every class and function, multi-edits and patches that apply all or nothing, test runners for a dozen stacks, dev servers in the background.
  • Checks every changeEach edit is syntax-checked and shown as a diff. Broken code, bad JSON or a page that links to a missing file goes straight back to the agent.
  • You set the leashAsk first, Auto or Full auto. Read-only commands never ask, builds and tests go ahead in Auto, and commands that could wipe a disk never run at all.
  • Second opinionAnother model reviews the changes or helps with a bug it is stuck on. /review /test /fix /init /try /undo in every project, @ to hand it files.
  • Best of severalHave two to four models do the same task at once, each in its own copy. Compare their diffs side by side and keep the best.
  • Long jobs, small modelsEvery request is kept inside the model's limits: old output is trimmed, earlier steps are summarized, and a too-large request is shortened instead of failing.
  • Your rulesReads AGENTS.md, CLAUDE.md, GEMINI.md, .cursorrules, .clinerules and friends. Hooks run your formatter after edits and your tests before it finishes.
  • In a terminalscorpi-code works in any folder; -p runs one task for scripts and CI. The folder shows up in the app with every change.

Under the hood

  • Python backendRuns on the standard library alone. Optional packages unlock documents, charts, voice and computer use, installed one by one so one failure never blocks the rest.
  • localhost:8000The UI is a web app served by your PC, in its own window or any browser.
  • ProvidersAny OpenAI-compatible /chat/completions or Anthropic-style /messages endpoint, plus coding plans.
  • PermissionsReading is allowed by default. Running code, controlling the PC, deleting and sending ask first, unless the command is known to be harmless. Set each tool to Allow, Ask or Off.
  • Your dataChats, settings and keys live in Scorpi's data folder next to the app. Nothing is sent anywhere except the provider you pick.
  • TestsUnit and end-to-end tests run against a mock model server: python -m unittest discover -s tests -t .

FAQ

Is it free?

Yes. Scorpi is free, and it works with free models: local ones through Ollama or the free tiers of cloud providers. Voices, maps, weather and search use free services too. Paid keys are optional.

Do I need a GPU?

No. With a cloud model any Windows 10 or 11 PC works. A GPU only matters for running models offline.

Where do my chats and keys go?

They stay in Scorpi's data folder on your PC. Prompts go only to the provider you picked, or nowhere with a local model.

Can I use my own coding plan or endpoint?

Yes. Add any OpenAI-compatible or Anthropic-style endpoint with your key. Coding plans such as OpenCode Go work as a model provider, and with the OpenCode CLI installed the Coder's full engine runs on any of your keys too, from OpenCode Go to NVIDIA, OpenRouter or Groq.

Do I need OpenCode for coding?

No. The Coder and the Code section work with Scorpi's own tools. For the full engine, install Node.js and run npm i -g @opencode/cli; Scorpi picks it up on its own. You can switch between Full and Basic under Connect.

Can it break things?

Anything that runs code, controls the PC, deletes or sends asks you first, unless you allow more. In a coding project, every run is saved as a checkpoint you can undo, commands that could wipe a disk or your home folder are refused outright, and Plan first lets you approve the plan before anything changes.

What may the agent do without asking?

You choose under Connect, Tools & permissions, or with Shift+Tab in a project. Ask first: only reading. Auto (the default): reading, builds, tests, running the project and file changes inside the project folder. Full auto: everything except destructive commands such as deleting folders or force pushes.

Is there a terminal version?

Yes: scorpi-code, in the app's folder. Run it in any project for an interactive session, or scorpi-code -p "task" for scripts and CI. It uses the app's models, keys and settings, and the folder shows up in the app.

Which free model is best for coding?

Set the coding model to Automatic and Scorpi picks the strongest coder among the services you added (Qwen3 Coder, Kimi K2, Devstral, gpt-oss and the like, marked best code). Add two or three free keys, so another one takes over when a free tier runs out.

How do I uninstall it?

Settings, Apps, Scorpi, Uninstall, or Scorpi-Setup.exe --uninstall --quiet. You choose whether chats and settings stay.

How do I verify the download?

Compare Get-FileHash .\Scorpi-Setup.exe with the SHA-256 at the bottom of this page. The PowerShell install does this for you.
